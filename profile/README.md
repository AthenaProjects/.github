### Focus
- **Plugins & Libraries:** High-performance utilities and mechanics for PaperMC (1.21+) & Leaf.
- **Architecture:** Asynchronous operations, lock-free concurrency, fast in-memory cooldowns, and Adventure MiniMessage.
- **Open Source:** Clean, lightweight tools built for modern Minecraft servers.
