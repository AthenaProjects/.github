### Focus
- **Plugins & Libraries:** High-performance utilities and mechanics for PaperMC (1.21+) & Folia.
- **Architecture:** Region-safe multi-threading, fast in-memory cooldowns, and Adventure MiniMessage.
- **Open Source:** Clean, lightweight tools built for modern Minecraft servers.
